# Task Management

1. **Plan First**: Write the high-level implementation plan in `tasks/plan.md`
2. **Verify Plan**: Check in before starting implementation
3. **Break Down Work**: After the plan is accepted, break it down into checkable items in `tasks/todo.md`
4. **Track Progress**: Mark items complete as you go
5. **Explain Changes**: High-level summary at each step
6. **Document Results**: Add a review section to `tasks/todo.md`
7. **Capture Lessons**: Update `tasks/lessons.md` after corrections
